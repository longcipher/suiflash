## Flash Loan Move API

### Borrow Function
```move
public fun flash_loan_with_ctx<CoinType>(
    config: &FlashLoanConfig,
    pool_id: ID,
    amount: u64
): (Balance<CoinType>, Receipt<CoinType>)
```

### Repay Function
```move
public fun flash_repay_with_ctx<CoinType>(
    clock: &Clock,
    storage: &mut Storage,
    pool_id: ID,
    receipt: Receipt<CoinType>,
    repay_balance: Balance<CoinType>
): Balance<CoinType>
```

## Flash Loan Fee

**Current Fee: 0.06% (6 basis points)**
- Initially: 0.2% (20 bps)
- Temporarily reduced to attract developers
- May change based on protocol governance

## Usage in PTB

```typescript
// 1. Borrow
const [balance, receipt] = tx.moveCall({
    target: `${NaviProtocolPackage}::lending::flash_loan_with_ctx`,
    arguments: [
        tx.object(flashloanConfig.id),    // 0x3672b2bf471...
        tx.object(pool.poolId),            // Pool ID for asset
        tx.pure.u64(amount),               // Amount to borrow
    ],
    typeArguments: [coinType]
});

// 2. User operations with borrowed funds...

// 3. Repay
const [returnedBalance] = tx.moveCall({
    target: `${NaviProtocolPackage}::lending::flash_repay_with_ctx`,
    arguments: [
        tx.object('0x06'),                 // Clock
        tx.object(StorageId),              // 0xbb4e2f4b620...
        tx.object(pool.poolId),            // Same pool ID
        receipt,                           // Receipt from borrow
        repayCoin,                         // Repayment balance
    ],
    typeArguments: [coinType]
});
```

## Notes for SuiFlash Integration

1. **Package ID**: Use `defaultProtocolPackage` or fetch latest via `getLatestProtocolPackageId()`
2. **Clock Object**: Always `0x06` (Sui system clock)
3. **Storage**: Shared mutable object at `0xbb4e2f4b6205c2e2a2db47aeb4f830796ec7c005f88537ee775986639bc442fe`
4. **Config**: Shared object at `0x3672b2bf471a60c30a03325f104f92fb195c9d337ba58072dce764fe2aa5e2dc`
5. **Receipt**: Hot potato pattern - must be consumed by `flash_repay_with_ctx`
